How the Match Prediction Works:

The match prediction system utilizes data from The Blue Alliance (TBA) API to predict the average scores for both the Red and Blue Alliances in a given match. Here's a breakdown of how the prediction is calculated:

  • Match Retrieval: The function starts by retrieving data for a specific match using its matchId, which is passed as a parameter in the URL. This includes the teams in each alliance and the event key.
  • Team Performance Analysis: For each team in the Red and Blue Alliances, the system collects their recent match results. It first attempts to retrieve match data from the current event, focusing on past matches played by each team. If there aren't enough recent matches, it falls back to retrieving data from the team's performance in the current season.
  • Match Scoring: The system gathers scores for each team based on the past three matches they've played, prioritizing the most recent ones. If fewer than three matches are available, the system will pull additional data from the team's seasonal matches until it has enough information.
  • Average Score Calculation: The average score for each alliance is calculated by averaging the scores from the past matches of each team in that alliance. These averages are then displayed as part of the prediction, with "N/A" displayed if a team does not have enough match data to compute an average.
  • Dynamic Display: The predicted average scores for both the Red and Blue Alliances are dynamically shown on the page. Each alliance's score box is interactive, allowing users to click on it to reveal additional details, such as the teams in the alliance and their individual performance stats.
This prediction model provides a data-driven estimate of the performance for each alliance based on recent historical performance, which can help users better understand the potential outcome of the match. Currently, this page is quite limited in functionality. However, with future updates, it is being planned to be expanded.
